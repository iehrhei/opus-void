# OPUS.VOID

*floating structures of sound*

An interactive, hand-inked cube of musical staves. Each of its six faces is a full page of score and a different material of sound — pure, glass, droplet, breath, distance, felt. Ink notes onto any face, then play them all at once and watch the lines between them build an architecture of sound.

**Live:** https://iehrhei.github.io/opus-void/

- **click** a staff to ink a note · click again to erase · **shift** for sharp
- **double-click** a face to write up close · ← → ↑ ↓ to move between faces · **esc** back
- **space** to play · **V** to enter the void · **⌘Z** / **⇧⌘Z** undo / redo
- **share** turns the whole structure into a code anyone can open

Built with Three.js and the Web Audio API. Single file, no build step.
